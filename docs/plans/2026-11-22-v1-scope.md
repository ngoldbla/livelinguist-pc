# Live Linguist PC — v1.0 scope freeze

- Date: 2026-11-22
- Status: **proposed v1.0 scope.** Supersedes the wider v1 items in
  `docs/plans/2026-11-21-live-linguist-pc-master-plan.md` for the 1.0 release
  only. The master plan is updated after the current Windows PR stack merges.
- Assumptions: **one screen**, **Windows 11 x64**, **lower-end or integrated
  GPU**, system audio as the primary source.
- Decision record: `docs/decisions/0018.md`.
- Execution plan: `docs/plans/2026-11-22-v1-execution-plan.md`.

## 1. What v1.0 is

A single-screen Windows 11 user can install without admin, join a Zoom/Teams/
Meet/Skype call or play a YouTube video, see live captions where a passing ASR
model exists, click any sentence to get a simpler same-language version in any
of the **29 supported languages**, keep the compact overlay above the call
without losing focus, export the transcript, and uninstall cleanly. Nothing
leaves the device except an explicit model download.

**Success sentence:** "I installed it, started a YouTube video, and got readable
captions and one-click simplification in my language — without a microphone, a
cloud account, or an admin prompt."

**Language rule:** all 29 FrameworkPacks and 29 UI catalogs ship. The
simplifier is available in all 29 through clicked captions (where live ASR is
available) or typed/pasted text. Live caption coverage is measured per locale;
it is not capped at five. Only phrases the user clicks are simplified.

## 2. Supported system

| Item | v1.0 floor | Recommended |
|---|---|---|
| OS | Windows 11 23H2 x64 | Windows 11 24H2+ |
| CPU | 4 cores, AVX2 | 6+ cores |
| RAM | 8 GB | 16 GB |
| GPU (UI) | D3D11 feature level 11_0, hardware | Integrated or discrete |
| Display | one screen, 1280x720, 100% | 1920x1080, 100/125/150% |
| Audio | one default render endpoint (loopback) | headset or speakers |
| Disk | 6 GB free (app + models) | 10 GB |
| Admin | not required (per-user install) | — |

**Not supported in v1.0:** software/WARP-only rendering (best-effort, shown as
degraded), Windows 10, ARM64, multi-monitor, mixed-DPI, microphone, per-app
capture, exclusive-mode fullscreen games.

## 4. v1.0 user journey

1. Install per-user (no admin), launch, choose learning language and UI locale.
2. Download the 0.6B model and, if the language has a passing live ASR model,
   that ASR model (hashed).
3. Choose **System audio**; the app captures the default output via loopback.
4. Start a Zoom/Teams/Meet/Skype call or a YouTube video.
5. Live captions appear **verbatim** in the console; there is no automatic
   simplified line. Switch to the compact overlay to keep them above the call;
   the overlay never steals focus and can be dragged.
6. Click any sentence to simplify it in the same language. The simplifier works
   in all 29 packs; for a language without live ASR, paste/type text instead.
7. Pause/resume, switch modes, export or clear the transcript.
8. Uninstall; models are removed only when the user asks.

## 6. Explicitly deferred from 1.0

- Multi-monitor and mixed-DPI; virtual-desktop pinning.
- Microphone capture and per-app audio capture.
- Automatic/live simplification. **Click-only is the v1.0 product rule**, not a
  temporary default; no phrase is simplified without a click.
- 1.7B model and GPU inference (Vulkan/CUDA); GPU calibration.
- Full RTL chrome mirroring.
- Windows 10, ARM64, Linux packaging, macOS.
- Auto-update, telemetry, cloud inference, translation, speaker diarization.
- Additional live ASR models for locales beyond the measured coverage.

## 7. Risks and stop rules

- **ASR quality:** if a language misses the WER/RTF gate, ship it as
  `simplify_only`; do not fake listening. Live coverage is separate from the
  29-language simplifier, so this is a scope reduction, not a blocker.
- **Low-end latency:** if 0.6B Q4 misses the p95 budget on tier C, reduce
  threads and ship the verbatim fallback with a banner. Do not add a GPU
  dependency to rescue it.
- **Loopback failures:** if default-endpoint loopback fails on a device, show a
  clear unsupported-device banner and keep file/typed input. Do not silently
  capture a different device.
- **Overlay:** if topmost/no-activate fails on a user's system, use the honest
  normal-window + banner fallback (D-010).
- **Installer:** if NSIS per-user install fails, portable ZIP remains the
  supported path for 1.0; do not require admin.

## 8. Impact on the existing plan

For the 1.0 release this narrows or supersedes:

- D-014/D-015 (GPU accelerator/Vulkan/CUDA) → CPU-only inference.
- D-030/D-040 (1.7B escalation and GPU ladder) → 0.6B CPU → verbatim.
- W-2 microphone-first → loopback-first; mic deferred.
- W-1 mixed-DPI/multi-monitor and virtual-desktop pinning → deferred.
- The five-language cap is removed: **all 29 packs ship**; live ASR is per
  measured coverage with en/fr/de/es/ar as the minimum live set.
- Automatic/live simplification → **not in 1.0**; click-only is the product
  rule.

Everything else (one window, Win32 overlay, GPUIX, sherpa-onnx, llama.cpp,
pinned models, privacy, content-free diagnostics, per-user install) stays.
