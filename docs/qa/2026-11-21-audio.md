# Audio dev evidence (S-5L partial)

- Date: 2026-11-21
- Status: **partial** — file/demo/silence replay, WAV decode, resampling, VAD,
  chunking, silence gate, and the 10-second ring buffer are implemented and
  tested. Live PipeWire/WASAPI capture is the remaining device task.

## Implemented and tested

- `decode_wav`: RIFF/WAVE PCM16/PCM24/float32, mono/stereo downmix.
- `resample_linear`: deterministic 48k -> 16k and same-rate identity.
- `AudioChunker`: 17,600 samples / 1.1 s, zero-padded flush.
- `VoiceActivityDetector`: 20 ms frames, RMS threshold, 300 ms hangover;
  `total_voiced_duration` for the pipeline's silence backstop.
- `SilenceGate`: admission by voiced-frame count, pre-roll carry, and
  words-per-voiced-second plausibility.
- `AudioRingBuffer`: 10 s at 16 kHz (160,000 samples), counts overflow events
  and dropped samples in milliseconds.
- `SyntheticSource` / `FileSource` / `ChannelSource`: demo, eval, and a
  queue-backed seam for a capture worker.
- `tests/fixtures/sample.wav`: 3.0 s synthetic, non-PII, generated by
  `scripts/gen-fixture-wav.py`.

```bash
cargo test -p ll-audio          # 9 tests pass
cargo run -p ll-eval -- --scenario mock --language fr-FR \
  --wav tests/fixtures/sample.wav --out /tmp/ll-eval-wav
```
