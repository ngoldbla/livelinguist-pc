## Known gaps (honest)

- No real ASR or GGUF model is installed; the UI/engine use the scripted demo
  and deterministic demo simplifier. All 29 ASR rows remain `tbd` ->
  effective `simplify_only`.
- The `llama` and `sherpa` feature seams return explicit errors/unavailable
  states instead of loading models; the model catalog is unpinned and refuses
  downloads until publish-time hashes are committed.
- WASAPI/PipeWire device capture, the 30-minute audio soak, Win32 acceptance,
  D3D UI, and clean Windows install are pending the dual-boot Windows side.
- No live-region API in GPUIX 0.11; "Read latest" is the documented fallback
  (Q-010/Q-013).
- Full RTL row mirroring is partial; Arabic text/locale and `isRtl` are in
  place, GPUIX lacks a direction primitive.
- The 10-minute TSFN soak passed under Node and Bun; see
  `2026-11-21-event-delivery.md`.
