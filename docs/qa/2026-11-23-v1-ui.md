## Keyboard

Implemented (T27):

- Caption rows (`CaptionRow` in `ui/src/aurora/components.tsx`) are
  `role="button"`, `tabIndex=0`, with the focus ring (`focusVisible`).
  Tab reaches the list; **Up/Down** (also Home/End) move between sentences;
  **Enter/Space** runs the same simplify call as a click.
- Accessible label = sentence text + state: `Click to simplify`, `Simplifying`,
  or `Simplified: <text>` (UI only, never logged).
- **Read latest** button label shows `Ctrl+Shift+L`; the shortcut works
  window-wide (GPUIX window `onKeyDown` → `windowKeys` bus in
  `ui/src/captionKeys.ts`).
- **Announce method:** GPUIX 0.11 has no live-region/announce API, so Read
  latest moves keyboard focus to the latest caption row (newest simplified,
  else newest). The screen reader reads the row's label.
- GPUIX has no imperative `focus()`. Moving focus remounts the target row with
  `autoFocus`. Focus moves only after the user's own key press.

Evidence: `bun test src/captionKeys.test.ts` — 9 tests on the pure handler
(index + key → index/action, shortcut, label, latest-row choice, key bus).

Pending (Windows): a keyboard-only run (no mouse) that starts a session, moves
to a caption, simplifies it, and uses Read latest; `verify-windows.ps1 -A11y`
still passing; focus ring visible at 100/125/150%.

## Contrast

`ui/src/aurora/contrast.test.ts` computes WCAG 2.x contrast for every text
token on every opaque background (`bg`, glass `surface` composited over `bg`,
`surfaceSolid`, `surfaceRaised`). It also covers badge text on its own fill,
primary/danger button labels, and large text/focus ring at 3:1.

Two fixes, both the smallest change that passes:

| Token | Was | Now | Worst ratio before → after |
|---|---|---|---|
| `colors.faint` (small hint text) | `#6F6A85` | `#87829D` | 3.22 → 4.51 on `surfaceRaised` |
| Primary button fill (white label) | `#8B7CFF`→`#5F4BE8`, hover `#9A8CFF`, active `#7B6BF0` | `#7263E6`→`#5F4BE8`, hover `#7466D9`, active `#6656DD` | 2.77 → 4.52 |

All 52 contrast assertions pass.

## Reduced effects

The **Reduced effects** setting turns off the live Aurora glow
(`AuroraField active={screen === "live" && !settings.reducedEffects}`). The UI
has no animations (no `motion` or timers in `ui/src`), and GPUI redraws only
when state changes, so there is no frame loop to cap. The old setting text
promised a "30 fps target". It now says what the setting does.
