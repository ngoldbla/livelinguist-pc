# 0004 — Overlay strategy: Win32 primary

- Status: accepted
- Date: 2026-11-21
- Decision IDs: D-007
- Master plan: `docs/plans/2026-11-21-live-linguist-pc-master-plan.md`

## Context

The caption overlay must stay above a call/video and must not steal focus when clicked. GPUIX has one window and no cross-platform always-on-top API.

## Options

Win32 `HWND_TOPMOST` + `WS_EX_NOACTIVATE` + a `WM_MOUSEACTIVATE` subclass gives real topmost/no-activate behavior. X11 EWMH gives a usable dev path. Native Wayland layer-shell is not available on GNOME/Mutter and needs an upstream GPUIX addition.

## Decision

Win32 is the release-gated overlay path. Linux X11/XWayland is best-effort dev only. Native Wayland layer-shell is a future track. Fallback is an honest normal window plus an in-app banner, never silent.

## Consequences

Easy: real focus retention on the product platform. Hard: per-platform native policy code and a Windows acceptance machine. Revisit if Win32 topmost fails over full-screen video/call (S-6W).
