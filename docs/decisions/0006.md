# 0006 — Live budget per hardware tier

- Status: baseline
- Date: 2026-11-21
- Decision IDs: D-051
- Master plan: `docs/plans/2026-11-21-live-linguist-pc-master-plan.md`

## Context

The Mac's latency numbers do not transfer to x86. Budgets must be measured per hardware tier, and tier C must degrade honestly.

## Options

Plan targets: tier A live p50 <= 1.5 s, tier B <= 2.5 s, tier C on-demand only with <= 8 s p95. Measurements require the reference Dylan PC (dual boot) with exact specs.

## Decision

Adopt the targets as hypotheses. Instrument every stage; fail a tier only on measured p95. On tier C the defaults are on-demand, 0.6B Q4, 2-3 threads, verbatim fallback.

## Consequences

Easy: a measurable acceptance rule. Hard: true tier C needs a low-end machine or VM; the GPU-less Dylan PC is only an approximation. Revisit after S-4/S-5W numbers land.
