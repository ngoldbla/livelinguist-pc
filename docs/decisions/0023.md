# 0023 - Open source under MIT; public GitHub Releases for non-technical users

- Status: proposed (owner confirms the two open questions below, then flips the repo public)
- Date: 2026-11-25
- Decision IDs: D-060
- Related: 0015 (Windows-only v1), 0018 (v1.0 scope), 0020 (code signing),
  0021 (packaging layout); plan `docs/plans/2026-11-25-public-release-plan.md`

## Context

The owner wants the repository public under the MIT license and wants
non-technical Windows users to download and run release builds from GitHub
without help. Before this ADR the metadata disagreed: `LICENSE` was MIT, while
`NOTICE`, the workspace `Cargo.toml` and ADR 0020 said "MIT OR Apache-2.0".

Going public also unlocks things the release depends on: SignPath Foundation
free code signing (ADR 0020 requires a public OSI-licensed repo), free hosted
Windows runners, and build-provenance attestations.

## Decision

1. **License: MIT only.** `LICENSE`, `NOTICE`, the workspace `Cargo.toml`
   (`license = "MIT"`) and `ui/package.json` say MIT. Third-party components keep
   their own licenses (`packaging/licenses/THIRD_PARTY.md`). Apache-2.0 parts
   (sherpa-onnx, GPUIX/GPUI, the Qwen3 fine-tune) are compatible with an MIT
   app, provided their notices ship in `licenses/` (they do).
2. **Models stay out of the repo and the installer.** The app downloads them on
   first run from the pinned public Hugging Face mirrors (ADR 0019). This keeps
   the NVIDIA Open Model License (Nemotron ASR) out of the MIT distribution.
3. **Distribution is GitHub Releases.** One release per version, built only in
   CI from the tagged source. Assets: `LiveLinguist-Setup-<ver>.exe` (the one
   button for regular users), `LiveLinguist-<ver>-portable.zip`, and
   `SHA256SUMS.txt`, plus a build-provenance attestation. The release notes
   start with a three-step "Download, open, follow the setup" block and a
   picture of the SmartScreen step until signing lands.
4. **Signing follows ADR 0020.** 1.0.0 may ship unsigned; apply to SignPath
   Foundation the day the repo goes public, and sign 1.0.x once accepted.

## Open questions (owner)

- **Rights to the framework packs.** `assets/packs/` was ported verbatim from
  the macOS `live-linguist` repo, and `THIRD_PARTY.md` says "Distribution
  requires the same rights as the Mac app". Publishing them under MIT needs the
  owner to hold those rights (or to license the Mac repo's packs the same way).
  The packs cite national easy-language standards; check that the prompt text
  paraphrases rather than copies them.
- **Repo history goes public as is.** A scan on 2026-11-25 of all 109 commits
  found no tokens, keys, `.env` files, personal paths or emails (authors use
  GitHub noreply addresses). Docs include owner-PC hardware details (GPU model,
  screen size), which are fine to publish.

## Consequences

Easy: clear license and a free path to signing and CI. Hard: issues and
support requests arrive from non-technical users, so the release needs a
"Something didn't work" issue form that asks for the content-free diagnostics
export, never transcripts.

## Revisit when

SignPath answers, or a contributor asks for an Apache-2.0 patent grant.
