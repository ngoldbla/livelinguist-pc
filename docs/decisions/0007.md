# 0007 — UI framework: GPUIX + React

- Status: baseline
- Date: 2026-11-21
- Decision IDs: D-001
- Master plan: `docs/plans/2026-11-21-live-linguist-pc-master-plan.md`

## Context

The UI must be a native GPU-rendered window (no Electron/webview), with one morphing window and a TypeScript component model.

## Options

GPUIX 0.11.0 + React 19.2 is the recommended adapter, runs on Metal/DirectX/Vulkan, and exposes a11y roles, virtual lists, native input, motion, and automation. Solid is an alternative; a webview stack is forbidden by the product constraints.

## Decision

Use `@gpuix/react` and `@gpuix/native` exact-pinned at 0.11.0 with React 19.2.3. No Tailwind/DOM UI libraries. Build the Aurora components locally.

## Consequences

Easy: one codebase, native paint, automation hooks. Hard: pre-1.0 churn, one window, limited CSS subset. Revisit only together with both GPUIX packages and a migration plan.
