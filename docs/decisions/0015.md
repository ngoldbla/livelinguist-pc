# 0015 — Windows-only v1 scope

- Status: accepted
- Date: 2026-11-21
- Decision IDs: D-053
- Master plan: `docs/plans/2026-11-21-live-linguist-pc-master-plan.md`

## Context

Supporting Windows 10 and ARM64 doubles the test/packaging surface before the product has shipped.

## Options

Windows 11 23H2+ x64 is the product. Windows 10 and ARM64 are out of scope. macOS remains a separate later decision.

## Decision

Installer and portable ZIP target Windows 11 x64 only. The code stays portable for a future Linux track and a later macOS decision.

## Consequences

Easy: one installer, one OS matrix. Hard: excludes Windows 10 users. Revisit only with support evidence.

## Evidence

`docs/plans/2026-11-21-live-linguist-pc-master-plan.md` §3, §17.
