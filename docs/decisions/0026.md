## Context

The first complete PC UI passed its a11y counts and contrast tests but failed a
design review: 30-40% of most windows was empty, the console presented ten
competing signals, two toggles were inert, language status was repeated three
times, the overlay ignored the caption-size setting, preferences reset on every
launch, the current window mode was not shown, and metadata was 9-11px type
named after the implementation ("Tier 1", "ASR status").

The owner's macOS build is the reference for the flow. Its control window is a
small console: brand lockup, a state headline ("Ready to caption" / "Captioning"
/ "Paused"), two decision tiles (language, sound) that open menus, one note when
models are missing, and a bottom session cluster with one large Start/Stop and
the privacy line. Captions live in floating surfaces (overlay panel, transcript
sidebar); first run is a three-beat sheet (welcome/privacy, language, download)
where picking a language advances and the download is one aggregate bar; the
summary is a compact sheet of stat tiles with Export and Done; settings has
Captions, Models and Licenses tabs. The PC has one window, so it must carry the
same flow with the transcript as a screen and a small control row in the
overlay.

## Options

1. **Polish the first PC layout in place.** Keep the three-column console, the
   layered glass and the mode toggles; tune spacing and copy. Cheapest, but
   keeps the hierarchy, the empty canvas and the flow the Mac does not share.
2. **Adopt the Mac flow on the quiet visual system (chosen).** Structure,
   screen order, tile vocabulary and control placement follow the Mac build;
   the surface stays flat, high-contrast and dark, as the owner chose, rather
   than copying the Mac's glass/aurora rendering.
3. Copy the Mac visual world (glass tiles, gradient field, monogram) as well.
   GPUIX has no material/blur and the owner asked for the quieter utility look,
   so this would be a costume.

## Decision

Option 2.

- **Console (idle).** Brand lockup, 40px state headline, two 108px decision
  tiles side by side (LANGUAGE: value + capability; SOUND: value + what it
  captures), each opening a GPUIX Select menu, a model note only when models
  are missing, and a centered bottom cluster with one 48px Start and the
  privacy line. No mode tabs, no settings toggles, no model cards on the
  console.
- **Live.** Language name + session timer in the header, one cadence line
  ("Listening — keep talking", "Waiting for speech", "Simplifying…", "Paused",
  or "Tap a sentence to simplify it"), the transcript as the only content, rows
  with a 3px confidence bar and the simplified caption at the selected size, a
  2px amber border + EN badge on English reversion, and a centered Pause/Stop
  cluster with the privacy line. The three window modes sit beside the cadence
  because the PC needs them. The iOS input-level meter is omitted: the bridge
  exposes no level.
- **Overlay.** Caption panel: live partial above the last two finalized lines,
  sized from Settings, black 78% with a 16px radius and an orange border + EN
  pill on reversion. It keeps a single 26px control row (Pause, Move, Settings,
  Expand, Console window) only because the PC has no second window to escape
  through.
- **First run.** Welcome (brand, title, privacy card, Choose your language,
  demo), language (searchable list; picking advances), download (confirmation,
  one aggregate progress bar over all models, Download/Continue, demo, Back).
  No step rail or numbered progress.
- **Summary.** Compact sheet-like page: brand, title, 2x2 stat tiles (duration,
  language, sentences, target %), English reversions only when non-zero, the
  memory-only note, three export buttons and a primary Done. No transcript list.
- **Captioner.** The iOS captioner is the reference: language name and session
  timer in the header, one cadence line (error > paused > listening >
  simplifying > waiting > tap-a-sentence), rows with a 3px confidence bar and
  the simplified line at the caption size, and a 2px amber border with an EN
  badge on English reversion. The level meter is omitted because the PC bridge
  exposes no input level.
- **Icons and brand.** Lucide (ISC) paths are vendored as SVGs and rendered
  through `<svg source>`; the brand mark is the twin-L from the macOS repo on
  the indigo-to-azure tile. No SF Symbols (proprietary licence).
- **Type.** Segoe UI for chrome; M PLUS Rounded 1c (OFL 1.1, bundled, 3.4 MB)
  for simplified captions only. Latin and Japanese render in it; other scripts
  fall back to the platform face.
- **Settings.** Captions (verbatim, caption size 16-40, language detection, the
  product rule, App language), Models, Licenses, Developer. The App language
  control mirrors iOS: learning language or device language. Developer is the
  PC-only gated addition.
- **State.** `UiSettings` (caption size, verbatim, detection, developer,
  scenario) is read at boot and written on change to
  `%LOCALAPPDATA%\LiveLinguist\ui-settings.json` (XDG on Linux).
- **Windows.** Console 960x660, onboarding 960x680, summary 960x700, settings
  1000x860, expanded 1180x900, overlay 780x250; the transcript reading column
  is 820 and the console content column 640, matching the Mac metrics.

## Consequences

Easy: the app now has one obvious action at a time, the first screen fits, the
overlay is a caption panel rather than a toolbar, preferences survive a restart,
and the vocabulary matches the audience. The Mac and PC flows can be described
by the same five screens.

Hard: the PC can no longer re-read a finished transcript after Stop (export is
the way to keep it), and per-row validator details collapse into one plain
line. The overlay must carry a control row the Mac does not need. The App
language control offers learning or device, not an arbitrary third locale.
Nineteen strings ship in English in 28 catalogs until the translation pass.
Two assets now ship and need their notices kept current: Lucide (ISC) and
M PLUS Rounded 1c (OFL, +3.4 MB in the payload). The Select menu is a native
popover without search; the onboarding picker remains the searchable one.

## What would overturn it

- A request to review old transcripts on the PC: bring back the transcript on
  the summary or a history surface, not on the console.
- A real UI-locale menu with every catalog: extend `UiSettings` beyond
  learning/device and add it to Settings headers.
- An icon or font whose licence or coverage no longer fits: replace the vendored
  set, update `THIRD_PARTY.md`, the in-app Licenses tab and the packaging
  notices together.
- A second PC window (GPUIX roadmap): move the overlay controls out of the
  caption panel and drop them entirely.
