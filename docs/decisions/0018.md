# 0018 — v1.0 is single-screen, system-audio, CPU-first, click-to-simplify

- Status: accepted
- Date: 2026-11-22
- Decision IDs: D-055
- Master plan: `docs/plans/2026-11-21-live-linguist-pc-master-plan.md`
- Scope doc: `docs/plans/2026-11-22-v1-scope.md`

## Context

The master plan targets GPU tiers, multi-monitor correctness, microphone and
per-app capture, live simplification, and a 1.7B escalation. The Windows
acceptance work showed the cost of that breadth: Vulkan has no ICD on the
reference host, mixed-DPI/multi-monitor needs two displays, the microphone
endpoint is absent, and GPU calibration/packaging adds risk without serving the
initial Zoom/Teams/Meet/YouTube use case. A 1.0 needs a smaller, defensible
promise.

## Options

1. Keep the full plan and block 1.0 on extra hardware and model work.
2. Freeze a single-screen, system-audio, CPU-first, click-to-simplify 1.0 and
   defer the rest.
3. Ship only typed/pasted simplification and defer live captions.

## Decision

Option 2. v1.0 supports one Windows 11 x64 screen at 100/125/150%, captures the
default render endpoint via WASAPI loopback, runs streaming zipformer int8 ASR
on CPU (minimum live set en/fr/de/es/ar, plus every locale with a passing model),
and simplifies **only the phrases the user clicks** with Qwen3 0.6B Q4_K_M on
CPU. All 29 FrameworkPacks and 29 UI catalogs ship; locales without a passing
live ASR model remain fully usable through clicked captions where available and
typed/pasted text. There is no automatic or background simplification. The
Win32 no-activate overlay stays. No microphone, no per-app capture, no
multi-monitor, no GPU inference, no 1.7B, no auto-update. The full decision
table is in the scope doc.

## Consequences

Easy: a testable 1.0 on low-end/integrated-GPU hardware, a smaller installer,
all 29 language packs, and no dependency on undocumented virtual-desktop or GPU
APIs. Hard: live caption coverage varies by locale; external monitor users,
microphone users, and GPU owners get less; Arabic ships with RTL text but not
full chrome mirroring. Revisit when the ASR/LLM and loopback gates are measured;
the first post-1.0 candidates are microphone, multi-monitor, GPU acceleration,
and 1.7B.

## Addendum 2026-11-22

The ASR clause above says "streaming zipformer int8 ASR". sherpa-onnx is still
the runtime, but the model is NVIDIA Nemotron 3.5 streaming 0.6B (int8, 560 ms):
one model for all 29 locales, not a per-language set. See ADR 0019 and
`docs/qa/2026-11-22-model-pins.md`.
