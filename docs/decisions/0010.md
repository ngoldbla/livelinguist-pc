# 0010 — Developer settings and strict scenarios

- Status: accepted
- Date: 2026-11-21
- Decision IDs: D-018
- Master plan: `docs/plans/2026-11-21-live-linguist-pc-master-plan.md`

## Context

Failures must be reproducible and CI must be able to force CPU/no-GPU/mock/fault paths.

## Options

A developer panel with scenario presets, strict mode, runtime health, and fault injection makes degradation testable. Hidden fallback would make support impossible.

## Decision

Ship Settings -> Developer behind a master switch or `LIVELINGUIST_DEV=1`; persist `dev-overrides.json`; support Auto, CPU-only, No-GPU, Vulkan-only, CUDA-only, iGPU/dGPU, Mock, Tier C, Stress, ASR-only, LLM-only, Simplify-only. Strict mode fails loudly.

## Consequences

Easy: every degradation path is testable. Hard: more settings surface. Revisit only by removing a scenario that no test uses.

## Evidence

`core/crates/ll-config`; `ui/src/dev`.
