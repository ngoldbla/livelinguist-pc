# 0011 — Per-locale ASR coverage

- Status: accepted
- Date: 2026-11-21
- Decision IDs: D-031
- Master plan: `docs/plans/2026-11-21-live-linguist-pc-master-plan.md`

## Context

29 locales ship simplification, but streaming ASR quality varies and some locales have no usable model.

## Options

A false 'listening' state is worse than an honest simplify-only mode. The matrix is filled by S-3A/T-003; any locale not ok/degraded is simplify_only.

## Decision

Every locale has an explicit status (`ok`, `degraded`, `simplify_only`, `tbd`). `tbd` cannot ship as ok. Simplify-only locales show paste/type input and never a fake listening state.

## Consequences

Easy: honest UX and a clear model roadmap. Hard: some locales lack live captions in v1. Revisit when a locale passes the WER gate and its model is in the catalog.

`assets/packs`; `core/crates/ll-asr/src/coverage.rs`; `docs/qa/2026-11-21-asr-coverage.md`.
