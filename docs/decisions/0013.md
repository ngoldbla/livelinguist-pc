# 0013 — Platform order: Windows-first

- Status: accepted
- Date: 2026-11-21
- Decision IDs: D-023/D-053
- Master plan: `docs/plans/2026-11-21-live-linguist-pc-master-plan.md`

## Context

The product owner's market is Windows 11; the development machine dual-boots Linux and Windows.

## Options

Windows 11 x64 is the only v1 release target. Linux x86-64 is the development/eval environment; Linux packaging is a future track. Windows 10 and ARM64 are out of scope. Windows acceptance uses the real Windows side, not a VM.

## Decision

Milestone order M2 = Windows app, M3 = Windows release. Every CI run includes Windows; Linux dev smoke is optional and never gates a release.

## Consequences

Easy: one release target and real hardware acceptance. Hard: dual-boot iteration cadence (X-024). Revisit only with a new platform decision.
