# 0014 — GUI floor: D3D11/12 on Windows, Vulkan on Linux dev

- Status: accepted
- Date: 2026-11-21
- Decision IDs: D-024
- Master plan: `docs/plans/2026-11-21-live-linguist-pc-master-plan.md`

## Context

GPUIX renders through GPUI. A no-GPU GUI path would require a second UI stack, which is out of scope.

## Options

Windows 11 ships D3D11/12 broadly; Linux dev machines have Vulkan (lavapipe is best-effort). Software rendering is degraded, not a release target. CPU-only applies to models, not the UI.

## Decision

Windows UI floor is D3D11/12; Linux dev floor is Vulkan. WARP/Lavapipe are best-effort and must never be claimed as 60 fps.

## Consequences

Easy: one renderer path. Hard: no GUI on machines without a supported GPU. Revisit only with a second UI stack decision.
