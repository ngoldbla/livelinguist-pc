# 0009 — Inference backends and calibration

- Status: baseline
- Date: 2026-11-21
- Decision IDs: D-013/D-014/D-015/D-040
- Master plan: `docs/plans/2026-11-21-live-linguist-pc-master-plan.md`

## Context

GPU availability and speed vary; the app must work without a GPU and use one when it actually wins.

## Options

Dynamic llama.cpp backends (`backends/cpu`, `cpu-vulkan`, `cpu-cuda`) plus device enumeration and a fixed-prompt calibration. A 2-D ladder (model size x backend) degrades to verbatim.

## Decision

CPU baseline; Vulkan universal; CUDA optional. Calibrate on first run, cache by hardware/driver/model hash. Ladder: 1.7B GPU-full -> 1.7B GPU-partial -> 1.7B CPU -> 0.6B GPU-full -> 0.6B CPU -> verbatim.

## Consequences

Easy: no hard GPU requirement. Hard: packaging multiple backend modules and calibration time. Revisit if iGPU calibration never beats CPU.
