# 0020 - Code signing for v1.0

- Status: accepted
- Date: 2026-11-23
- Decision IDs: D-057
- Related: 0015 (Windows-only v1), 0018 (v1.0 scope)

## Context

Unsigned Windows installers trigger Microsoft Defender SmartScreen ("Windows
protected your PC") until the file builds download reputation. Live Linguist PC
is a free, open-licensed (MIT OR Apache-2.0) indie project with no company
entity and no signing budget. The product owner is new to Windows distribution
and asked for the best path.

## Options

1. **Ship unsigned** with published SHA-256 sums and instructions for the
   SmartScreen prompt ("More info → Run anyway"). Free, works today.
2. **SignPath Foundation (free OSS signing).** SignPath issues a certificate
   held by the SignPath Foundation for eligible open-source projects (OSI
   license, source public, release built in CI from that source). The publisher
   shown is SignPath Foundation, not the developer. Free; needs an application
   and a CI integration; approval takes time.
3. **Azure Artifact Signing (formerly Trusted Signing).** Microsoft-managed
   certificates, billed monthly (Basic/Premium tiers); identity validation;
   eligibility for individuals is limited by region. Low cost, but recurring
   and needs an Azure account.
4. **Buy an OV/EV certificate** from a CA. Hundreds per year, hardware token
   or cloud HSM, identity checks. EV no longer grants instant SmartScreen
   reputation, so it buys little over option 3 for this project.

## Decision

- **v1.0.0 ships unsigned** (option 1): installer and portable ZIP with
  SHA-256 sums on the GitHub release, and a short "first run on Windows"
  section in the release notes and README showing the SmartScreen step.
- **Apply to SignPath Foundation now** (option 2). The account owner submits
  the application; the agent prepares the CI side (signing step in
  `.github/workflows/release.yml` gated on the SignPath action being
  configured, no secrets in the repo). Once accepted, ship v1.0.x signed.
- **Fallback:** if SignPath declines or the repo cannot be public, revisit
  option 3 with current pricing and eligibility before any purchase.
- Never commit certificates, keys, or tokens; signing happens only in CI.

## Consequences

Easy: zero cost, no blocker for 1.0, no secrets. Hard: early users see a
SmartScreen warning and must trust the published hashes; the signed publisher
name will be SignPath Foundation, not the project.

## Revisit when

SignPath responds, the repository visibility changes, or download volume makes
reputation-building matter more than cost. Verify current program terms and
prices at that time; they change.
