# 0008 — Window modes and overlay policy

- Status: baseline
- Date: 2026-11-21
- Decision IDs: D-004/D-008/D-009/D-010
- Master plan: `docs/plans/2026-11-21-live-linguist-pc-master-plan.md`

## Context

One GPUIX window must serve console, compact caption overlay, and expanded transcript without a second process.

## Options

Mode table in plan §10.1. Overlay is pointer-first and no-activate; console/expanded allow keyboard. Clicking a caption must not steal focus from the call.

## Decision

Console: decorated, topmost off, taskbar on. Overlay: compact bottom-center bar, topmost, skip taskbar, no-activate, all workspaces. Expanded: larger transcript, keyboard allowed. Policy is applied atomically and session state survives.

## Consequences

Easy: one window, one session. Hard: mode-specific accessibility; overlay is pointer-first (D-046). Revisit if simultaneous overlay+sidebar becomes mandatory (Q-004).

## Evidence

`core/crates/ll-window`; `ui/src/screens`.
