# M PLUS Rounded 1c

`MPLUSRounded1c-Medium.ttf` is the Medium weight of M PLUS Rounded 1c, licensed
under the SIL Open Font License 1.1 (`OFL.txt`).

- Source: `google/fonts` → `ofl/mplusrounded1c`, upstream
  <https://github.com/coz-m/MPLUS_FONTS>
- Copyright 2016 The M PLUS Project Authors.
- Used only for simplified captions (`fonts.rounded` in `src/aurora/theme.ts`).
  Latin and Japanese render in this face; scripts it does not cover fall back
  to the platform face, as SF Rounded does on Apple platforms.
- Packaging copies this folder to `fonts\` beside `livelinguist.exe`; the UI
  reads it from there (or from `ui/assets/fonts` in development).
